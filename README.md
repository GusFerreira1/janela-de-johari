
# Janela de Johari

A Janela de Johari é uma atividade de autoconhecimento que ajuda a entender como me vejo e como sou percebido pelas outras pessoas.

## As quatro áreas

- **Aberto:** características conhecidas por mim e pelos outros.
- **Ponto Cego:** características percebidas pelos outros, mas não por mim.
- **Oculto:** características que conheço, mas não compartilho.
- **Desconhecido:** características ainda não identificadas por mim ou pelos outros.
